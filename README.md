# Data Jobs Analysis with R

# Overview

It's a set of "R" scripts designed to clean, organize, analyze, and visualize data, transforming it into valuable insights for people looking for careers in the data field.

The data was provided through a dataset from Kaggle. The scripts were developed in R using dataframes to organize and filter data.One script demonstrates at least five different R data types, a for loop working with a list, and simple outputs. Another script answers two questions to help people searching for jobs in the data field: 
1- Which job categories have the highest number of joB opportunities? 
2- How does the average salary vary by experience level?
